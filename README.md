# Paintmaxxing

Paintmaxxing — это приложение для рисования, написанное на Python с использованием библиотеки PyQt5. Оно предоставляет пользователю инструменты для рисования произвольных линий, фигур и граффити с помощью мыши или планшета.

## Особенности

- **Рисование линий**: Пользователи могут рисовать произвольные линии с настраиваемой толщиной и цветом.
- **Инструменты**: Поддержка различных инструментов, таких как линия, ластик, граффити, прямоугольник, круг, эллипс и стрелка.
- **Палитра цветов**: Встроенная палитра цветов для быстрого выбора цвета пера.
- **Настройка толщины**: Возможность настройки минимальной и максимальной толщины пера.
- **Зум и панорамирование**: Поддержка зума и панорамирования для удобного рисования.
- **Сохранение изображений**: Возможность сохранения рисунков в форматах JPG и PNG.
- **Отмена и повтор**: Функции отмены и повтора действий для удобного редактирования.

## Установка

### Предварительные требования

- Python 3.x
- PyQt5

### Шаги установки

1. **Склонируйте репозиторий**:

    ```sh
    git clone https://github.com/lukchau/paintmaxxing.git
    ```

2. **Установите зависимости**:

    ```sh
    pip install -r requirements.txt
    ```

3. **Запустите приложение**:

    ```sh
    python src/app.py
    ```

## Использование

1. **Запустите приложение**:

    После запуска приложения вы увидите окно с тулбаром и рабочей областью для рисования.

2. **Выберите инструмент**:

    Используйте тулбар для выбора инструмента (линия, ластик, граффити и т.д.).

3. **Настройте параметры**:

    Вы можете настроить толщину пера и выбрать цвет из палитры.

4. **Рисуйте**:

    Используйте мышь или планшет для рисования на рабочей области.

5. **Сохраните рисунок**:

    Используйте меню для сохранения рисунка в формате JPG или PNG.
